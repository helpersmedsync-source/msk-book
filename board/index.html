How XP is earned

  • 1 for each page you read, 10 more when you finish a lecture
  • 3 for each correct answer in your best lecture quiz score
  • 5 for each question-bank question you have ever answered correctly
  • 1 for each flashcard reviewed, 2 more once it is learnt (a week or more between reviews)

Doing the same page or question again adds nothing, so the only way up is to cover more. Weeks run Saturday to Friday. The board shows usernames only; you can hide yourself in Account and settings.
